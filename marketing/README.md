# BuildTrack · Marketing landing

A small public landing page that points visitors at the working ERP demo.

The page is original copy describing the product's actual capabilities (per
the `README.md` in the repository root). It uses the same coral + navy colour
tokens as the operator app so the marketing site and the product feel like
one suite.

## Run locally

```sh
cd marketing
npm install
npm run dev    # → http://localhost:5175
```

The actual operator console lives at `http://localhost:5173` once you start the
`web-app` dev server; the admin panel is at port 5174.
